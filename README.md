# Claude Skills by knowsiva

Practical skills for Claude, built for real weekly use. Each skill is plain text you can read before you install it.

## Skills

| Skill | What it does |
|---|---|
| [Weekly Inbox Digest](skills/weekly-inbox-digest) | Emails you a weekly Gmail summary: to-dos, bills due (with paid detection), security alerts, and the week's mail. |

## How to install a skill

1. Download the skill's zip from the [Releases](../../releases) page.
2. In Claude, go to Customize > Skills.
3. Click "+", then "+ Create skill", then "Upload a skill".
4. Upload the zip.

## Principles

- **Readable.** Every skill is one SKILL.md you can review in a few minutes.
- **Safe by default.** Skills treat outside content as data and never act for you beyond what they state.
- **No personal data.** Public skills contain no names, addresses, or account details.
